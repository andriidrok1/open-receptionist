# Сценарий тестирования голосового агента

Прогон вручную через браузерный клиент. Говоришь по-украински, слушаешь/смотришь реакцию.

## Подготовка

```bash
cd ~/PycharmProjects/hotel-voice-agent && source .venv/bin/activate
cd server
python seed_demo.py          # (опц.) демо-данные, чтобы дашборд был не пустой
python bot.py                # терминал 1 → агент на :7860
# в отдельном терминале, чтобы видеть брони вживую:
python dashboard.py          # терминал 2 → дашборд на :8000
```
Открой `localhost:7860/client` → **Connect** → разреши микрофон.
Дашборд открой на `localhost:8000` (обновляется каждые 15 сек — новые брони всплывут сами).

**Совет:** называй себя редким именем (напр. «Тарас Тестовий»), чтобы легко найти свою бронь среди демо-данных.

## На что смотреть всё время (сквозные метрики)

- **Задержка** ответа: комфортно < ~1.5 сек. Если «висит» дольше — заметь на каком шаге.
- **Качество украинского голоса**: акцент, естественность, ударения.
- **Точность распознавания**: понимает ли числа, даты, имя, телефон.
- **Перебивание**: режет вовремя? Не срабатывает ли на фоновый шум?

## Сценарии

### T1 — Приветствие
Просто подключись, ничего не говори.
**Ожидание:** агент сам здоровается первым, коротко, представляется Оксаной, спрашивает чем помочь.

### T2 — Инфо-вопрос (без брони)
Скажи: **«О котрій годині заїзд і виїзд? Сніданок включений?»**
**Ожидание:** заезд с 14:00, выезд до 12:00, завтрак включён. Не начинает бронь без запроса.

### T3 — Happy path (основной)
Скажи: **«Хочу забронювати покращений номер з чотирнадцятого по сімнадцяте липня, на двох.»**
**Ожидание по шагам:**
1. Проверяет наличие (вызов `check_availability`), называет цену: Покращений 1800 грн/ночь × 3 ночи = **5400 грн**.
2. Спрашивает имя и телефон.
3. **Проговаривает всю бронь одним предложением и спрашивает подтверждение** («Отже… — все вірно?»).
4. Только после твоего **«так»** создаёт бронь и называет номер (`БР-XXXXXX`).
✅ Проверь потом: бронь появилась в дашборде и в базе.

### T4 — Подтверждение обязательно + смена
Во время T3, когда агент проговаривает бронь и ждёт «так», скажи: **«Ні, давайте краще делюкс.»**
**Ожидание:** бронь НЕ создаётся, агент пересчитывает под Делюкс (2800 × 3 = **8400 грн**), снова просит подтвердить. Создаёт только после «так».

### T5 — Дата словами
Скажи: **«Забронюйте стандарт на три ночі з двадцять п'ятого грудня, одна людина, Тарас Тестовий, телефон нуль шість сім, один два три, сорок п'ять, шістдесят сім.»**
**Ожидание:** агент правильно переводит «двадцять п'ятого грудня» → 2026-12-25, ночей 3 → выезд 28.12, цена Стандарт 1200 × 3 = 3600. Проверь даты в базе — не «уехали» ли на прошлый год.

### T6 — Плохие даты
Скажи: **«Заїзд сімнадцятого липня, виїзд чотирнадцятого липня.»**
**Ожидание:** агент замечает, что выезд раньше заезда, вежливо просит уточнить. Бронь НЕ создаётся.

### T7 — Перебивание (barge-in)
Начни бронь, и когда агент начнёт длинный ответ (напр. проговаривает бронь) — **перебей его на полуслове**, скажи «зачекайте».
**Ожидание:** агент **немедленно замолкает** и слушает тебя. Не «дочитывает» фразу поверх тебя.

### T8 — Off-topic / эскалация
Скажи: **«А чи можна з собакою? І чи є у вас спа-центр?»**
**Ожидание:** честно говорит, что уточнит у администратора / предложит записать контакт для обратного звонка. Не выдумывает факты.

### T9 — Шумоустойчивость (опц.)
Включи негромкий фон (музыка/ТВ) и говори.
**Ожидание:** не перебивает сам себя от фона, распознаёт твою речь. Если плохо — крутим `noise_reduction` / VAD.
